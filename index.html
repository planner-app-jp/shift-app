🔲 セルの枠の意味

🟧 オレンジ枠（不足の警告）
その日の AJ人数や日勤人数が規定より少ない 時に、その日のセル全体に表示。
※ 規定より多い場合は枠は付きません。
🟥 赤枠（ルール違反）
勤務ルールに違反しているセルに表示:
・AJペアが他より多い組み合わせ
・AJ の翌日が「明」になっていない
・AJ が2日連続している
・平日（祝日以外）に副島L・前田TLが両方とも勤務に入っていない

✏️ セルの編集方法（複数セル一括）

セルは1つずつタップして編集できます。複数セルをまとめて変更したい時は、下記の選択 → 一括編集バーを使うか、Excel/スプレッドシートで編集して「貼り付け」ボタンで取り込む方法が便利です。
💻 PC（Mac / Windows 共通）
① 複数セルを選ぶ
　・ドラッグ … セルを押しながら動かして範囲選択
　・連続範囲 … 始点クリック → 終点を Shift+クリック
　・飛び地 … Mac: ⌘+クリック / Windows: Ctrl+クリック で1つずつ追加・解除
② 画面下に出る一括編集バーで操作
　・勤務記号ボタン（A/B/C/AJ/BJ/CJ/公/有/K/E…）をクリック → 全選択セルに同じ値
　・「空白」「🔒固定」「🔓解除」も一括可能
　・「✕」または別セルを通常クリックで選択解除
③ ショートカット
　・Ctrl/⌘+Zで1つ前の操作に戻る
📱 スマホ（iPhone / Android 共通）
① 選択モードに入る
　・任意のセルを長押し（約0.5秒） → そのセルが選択され画面下にバーが出る
② 別のセルを追加
　・選択モード中に他のセルをタップ … 1セルずつ追加・解除
③ 一括編集バーで操作
　・記号ボタン（A/B/C/AJ/BJ/CJ/公/有/K/E…）をタップ → 全選択セルに反映
　・「残…」「空白」「🔒固定」「🔓解除」も使用可
　・「✕」で選択解除＆通常モードに戻る

📝 2段表示の切り替え

ヘッダーの 📝 2段ON / 2段OFF ボタンで2段目（メモ欄）の表示を切り替えできます。
・ON：上段に勤務記号、下段にフリーテキスト（出勤・健康診断 等）
・OFF：上段のみで正方形表示（コンパクトに見たい時用）

メモセルを右クリック（PC）／長押し（スマホ）で「黄色塗り」「赤文字」「クリア」を切り替えできます。

📅 Googleカレンダーに自分の勤務を入れる

ヘッダーの「📅 カレンダー」ボタンから、選んだ人の1ヶ月分の勤務をCSVで出力できます。Googleカレンダーにインポートすれば自分の予定として表示されます。
手順
① ヘッダーの「📅 カレンダー」をタップ
② 自分の名前と対象月を選んで「CSVダウンロード」
③ ブラウザで calendar.google.com を開く（PC推奨）
④ 左上の「⚙ 設定」→「インポート / エクスポート」
⑤ 「インポート」欄でダウンロードしたCSVファイルを選択
⑥ 「カレンダーに追加」で自分のカレンダーを選択
⑦ 「インポート」ボタンを押す → 完了
勤務 → 予定 の変換ルール
・AJ / BJ / CJ … 8:30 〜 9:00（30分予定として表示）
・A / B / C … 8:30 〜 17:00
・K / E … 8:30 〜 17:00
・残7 … 9:00 〜 17:00
・残4 … 8:30 〜 12:00
・その他の残業 … 8:30 〜 17:00
・公 / 有 / 明 … 終日予定
💡 ヒント: 専用カレンダー（例:「勤務」）を新規作成してそこにインポートすると、不要になったときカレンダーごと削除できて便利です。

💾 バックアップ／復元

⚠️ 大事な編集の前・機種変更／アプリ削除前は必ずバックアップを
ヘッダーの 💾 バックアップ でJSONファイルが保存され、📥 復元 で読み込めます。データが消える主な原因: PWA削除／キャッシュ削除／iPhone Safari 7日未使用／機種変更。
💻 PCの場合
① 💾 バックアップ を押す → ダウンロードフォルダに shift_backup_YYYY-MM-DD.json が保存
② iCloud Drive・Google Drive・Dropbox などに置くか、メールで自分宛に送って保管
③ 復元する時は 📥 復元 → JSONファイルを選択 → 確認画面で「上書き」
📱 スマホの場合
保存：① 💾 バックアップ をタップ → ②「ファイルに保存」または共有メニュー → ③ iPhoneはiCloud Drive／ファイルアプリ、AndroidはGoogleドライブ／ダウンロードに保存
復元：① 📥 復元 をタップ → ② 保存したJSONを選ぶ → ③「上書き」で完了
✅ おすすめのタイミング
・月1回など定期的に保存（ファイル名に日付が入るので世代管理OK）
・大きな編集や自動生成の前
・機種変更・アプリ再インストール前
